# HaND. — Independent Works

Personal website maintained by [HaND. / VulcanEon](https://github.com/VulcanEon).

**Live:** https://vulcaneon.github.io/

A responsive, dependency-free brutalist project directory. Built with semantic HTML and CSS. Photographs supplied by the owner.

## Local preview

```sh
python3 -m http.server 8080
```

Open http://localhost:8080. Edit `index.html` for projects and `style.css` for the design. GitHub Pages publishes the root of `main`. All eight project links are ordinary direct links without `nofollow`, `ugc`, or `sponsored` attributes.
